# Changelog

## 0.1.0

- Added Gateway API Standard channel support for Standard clusters.
- Added GKE Dataplane V2 configuration.
- Added Workload Identity Federation configuration.
- Added private endpoint, Master Authorized Networks, and control-plane global access options.
- Added VPC-native secondary range and explicit CIDR support.
- Added multiple autoscaling node pools.
- Added Shielded Nodes, automatic repair, automatic upgrade, and surge settings.
- Added deletion protection, release channels, validation, expanded outputs, and a production example.
- Preserved the original single-node-pool input structure for migration compatibility.
